# ♟️ CyberChess Pro: WASM Edition (Project B)

> A high-performance chess application leveraging WebAssembly for client-side engine execution.

## 🚀 Key Features
*   **Zero Latency:** Stockfish engine runs in the browser thread, eliminating server round-trips.
*   **AI Coach:** Real-time "Win Probability" calculation using Sigmoid normalization of centipawn scores.
*   **Smart Hints:** Interactive move suggestion engine.

## 🛠️ Tech Stack
*   **Frontend:** JavaScript (ES6), WebAssembly (WASM)
*   **Engine:** Stockfish.js (v10)
*   **Visuals:** Chessboard.js, CSS Grid
